# qr.b0r3d.org

b0r3d's QR code generator. Static codes only: what you type is encoded straight
into the pattern, so there's no redirect server and nothing that can expire.

Built on [Mini QR](https://github.com/lyqht/mini-qr) by Estee Tey, licensed
GPL-3.0. Work in progress.

`b0r3d-brand/` holds the b0r3d cup logo and favicon for the reskin.
